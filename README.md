# Augmented Reality for Self-Guided Electronics Soldering Education

## Overview

**Augmented Reality for Self-Guided Electronics Soldering Education** is a graduate-level Advanced Manufacturing Processes and Systems project focused on using augmented reality (AR) to support hands-on electronics soldering education.

The project will develop an interactive AR learning experience that guides students through the process of:

* Identifying electronic components
* Placing components on a circuit board
* Properly soldering components
* Inspecting completed work
* Troubleshooting common errors
* Following appropriate soldering safety practices

The goal is to create a self-guided laboratory experience that allows students to learn and complete the activity independently and at their own pace, while requiring minimal instructor assistance.

## Project Goals

The project will investigate how AR can improve hands-on technical education by providing students with visual, interactive guidance directly within the laboratory environment.

The AR experience will provide:

* Step-by-step visual instructions
* Component identification
* Circuit-board placement guidance
* Soldering technique demonstrations
* Safety instructions
* Progress checkpoints
* Feedback during the activity
* Basic troubleshooting and error guidance

## Primary Deliverable

The primary deliverable is a **self-guided AR laboratory module for teaching basic electronics soldering**.

The completed prototype will include:

### AR Instruction

Interactive, step-by-step AR instructions designed to guide students through the soldering activity.

### Component Identification

Visual guidance for identifying components and determining their correct placement on the circuit board.

### Soldering Guidance

Demonstrations and visual instructions covering proper soldering techniques and safety procedures.

### Progress Checkpoints

Checkpoints and feedback mechanisms that allow students to verify their progress throughout the activity.

### Troubleshooting

Basic error identification and troubleshooting guidance to help students resolve common mistakes.

### Self-Guided Learning

A structured laboratory activity designed to be completed with minimal instructor assistance.

## Evaluation

The project will include a brief evaluation of the AR module focusing on:

* Usability
* Student learning
* Effectiveness as a self-guided laboratory experience

The evaluation results will be documented along with the AR design and implementation process.

The project documentation is intended to support future enhancements to this laboratory module and the development of additional AR-based laboratory activities.
